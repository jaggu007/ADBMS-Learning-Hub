Text Search Basics

MongoDB text indexes allow language-aware full-text search. They are useful for products, articles, comments, and other documents where free-form text matters.

Key points

  • Create a text index on searchable fields.
  • $text performs case-insensitive search.
  • $language influences stemming and word matching.
  • Text search is best for document content rather than exact key lookup.

Text Search Basics in MongoDB

1. What is Text Search?

Text Search in MongoDB is a feature that allows us to search for specific words or phrases inside string fields of documents.

Example: Suppose a college database contains student project descriptions. We want to find all projects containing the word Artificial. A text index lets us search for matching words without manually checking every document.

Real-life example: Searching for machine learning in a collection of project descriptions, similar to searching for keywords in a search engine.

2. Sample Collection

Let's create a collection named projects and insert four sample documents.

use KIET

db.projects.insertMany([
  {
    title: "AI Chatbot",
    description: "An artificial intelligence chatbot"
  },
  {
    title: "Disease Prediction",
    description: "Machine learning for disease prediction"
  },
  {
    title: "Smart Farming",
    description: "Artificial intelligence in agriculture"
  },
  {
    title: "Student Portal",
    description: "A web application for student management"
  }
])

3. Why Do We Need a Text Index?

MongoDB requires a text index to perform text searches using the $text operator.

db.projects.createIndex({
  description: "text"
})
  • createIndex() creates an index.
  • description specifies the field to search.
  • "text" specifies the index type.

Check the indexes created on the collection:

db.projects.getIndexes()
Important: A collection can have only one text index, but that index can cover multiple fields.

4. Basic Text Search Queries

Example 1: Search for a Single Word

Find projects whose descriptions contain artificial.

db.projects.find({
  $text: {
    $search: "artificial"
  }
})

Expected matching projects:

TitleReason
AI ChatbotDescription contains “artificial”.
Smart FarmingDescription contains “artificial”.

MongoDB's default text search is generally case-insensitive for English text, so Artificial and artificial match equivalently.

Example 2: Search for Multiple Words

db.projects.find({
  $text: {
    $search: "machine learning"
  }
})

By default, MongoDB searches for documents containing either the word machine or the word learning. It does not require both words to be present.

Example 3: Search for an Exact Phrase

Find descriptions containing the exact phrase machine learning.

db.projects.find({
  $text: {
    $search: "\"machine learning\""
  }
})

The escaped quotation marks tell MongoDB to search for the phrase rather than treating the words as separate search terms.

Example 4: Exclude a Word

Find projects containing artificial but not agriculture.

db.projects.find({
  $text: {
    $search: "artificial -agriculture"
  }
})

This excludes documents matching the negative search term.

Example 5: Display Only Selected Fields

Find matching projects and display only their titles.

db.projects.find(
  {
    $text: {
      $search: "artificial"
    }
  },
  {
    _id: 0,
    title: 1
  }
)

Expected output:

{ title: "AI Chatbot" }
{ title: "Smart Farming" }

5. Search Across Multiple Fields

To search both title and description, create a text index on both fields:

db.projects.createIndex({
  title: "text",
  description: "text"
})

Then search both indexed fields:

db.projects.find({
  $text: {
    $search: "student"
  }
})
Note: If you already created the text index on description, drop it before creating the new index. The default index name is typically description_text.
db.projects.dropIndex("description_text")

ExampleSearch for artificialSearch for titles starting with AI

Regex example: find titles beginning with AI, ignoring case.

db.projects.find({
  title: {
    $regex: "^AI",
    $options: "i"
  }
})

7. Important Points to Remember

  • Create a text index before using $text.
  • Use $search to specify search terms.
  • Multiple words in a search string are generally treated as alternatives.
  • Use escaped quotation marks for exact phrase searches.
  • Use -word to exclude a term.
  • A text index supports keyword-based searching, not arbitrary substring matching.
  • MongoDB text search is not the same as a full search engine; advanced relevance tuning and language-specific behavior have their own limitations.

8. Practice Questions

Try these queries using the projects collection:

  1. Find all projects containing the word intelligence.
  2. Find projects containing either student or web.
  3. Find projects containing the exact phrase disease prediction.
  4. Search for artificial while excluding agriculture.
  5. Find matching projects and display only the title field.
Teaching tip: Run each query in mongosh, inspect the returned documents, and then modify the search words. This makes it easier to understand how the text index and $text operator work together.
